Контур ликвидности подрядчика

Как открыть модель:
1. Распакуйте архив в отдельную папку.
2. Откройте файл index.html двойным щелчком в браузере.
3. Файлы app.js и styles.css должны оставаться рядом с index.html.

Модель работает локально, подключение к интернету не требуется.
Внутри находятся демонстрационные данные, а не фактические данные компании.
Изменения сохраняются только в браузере пользователя.

Если браузер блокирует запуск локального файла, используйте опубликованную веб-версию.
